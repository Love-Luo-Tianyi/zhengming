## 二、只有你能做的（我无法代办）

### 1. 报名（历史时间节点，待官方复核）

- 入口：https://www.zhihu.com/hackathon/register?activity_code=zhihu_hackathon_2026_p2
- 需要：知乎账号登录（手机号一键登录）+ 按要求提报信息
- **需要上传身份证明**：在校生用学生证/学信网/录取通知书；毕业 3 年内用毕业证/学信网
- 报名后：添加官方助手 → 加入社群 → 组队（1–5 人，可跨校跨专业，也可单人参赛）

### 2. 申请开放平台凭证（决定作品能发挥几成）

- 入口：https://developer.zhihu.com/profile
- 需要拿到：**Access Secret**（Bearer 鉴权用）
- 拿到后做两件事：
  1. 打开 Demo 右上角「设置 → 数据来源 → 知乎开放平台实时」，粘贴 Secret —— **立即变成任意话题的实时拆解**
  2. 跑一次 `ZHIHU_ACCESS_SECRET=xxx node tools/fetch-answers.mjs`，把内置样本库从页面采集升级为官方接口检索，然后 `node tools/build-dataset.mjs && node tools/validate-dataset.mjs` 重建

### 3. 可选：配一个带模型的后端（评委体验最好）

公网静态站没有模型密钥，会降级到「本地回答体检规则」（界面会如实标注）。如果你希望评委看到**模型四维体检**的效果，把 `server/` 部署到任意 Node 环境即可：

```bash
ZHIHU_ACCESS_SECRET=xxx \
ZM_LLM_BASE=https://api.openai.com/v1 \
ZM_LLM_KEY=sk-xxx \
ZM_LLM_MODEL=gpt-4o-mini \
PORT=8787 node server/index.mjs
```

部署后在 Demo 右上角「设置 → 后端地址」填入地址，前端会自动切换，密钥全程不进浏览器。

> 关于知乎 OAuth：官方文档推荐接入（登录人数计入人气奖）。OAuth 需要 `app_id` + `app_key`，且在开放平台登记公网回调地址，**依赖上面第 2 步的凭证**。拿到凭证后我可以补上这部分。
