## 对争鸣的要求映射

| 官方关注点 | 当前实现 | 状态 |
|---|---|---|
| AI 重新定义连接 | 从问题与回答开始，报告页提供朋友复核分享入口 | 已实现最小闭环 |
| 观点/内容行为驱动发现 | 按回答立场、权威度、赞同数组织问题分歧地图 | 已实现；个人行为数据暂未接入 |
| 讨论参与 | 用户提交回应草稿，获得依据/切题/逻辑/增量体检 | 已实现 |
| 关系建立 | 分享 `#/arena/{topicId}`，邀请不同观点的朋友复核 | 已实现轻量版本 |
| 普通人快速上手 | 纯静态、无需登录、离线快照、首页点选即用 | 已实现 |
| 内容可信与合规 | 作者、回答 ID、原链接、短摘录、非官方/离线说明 | 已实现 |
| 官方 API / skill | 仓库保留可选适配层；默认不假装实时 | API 权限、官方 skill 文档和当期规则仍待官方确认 |

## 不应临时承诺的能力

- 模拟真实答主、代替答主发言或自动代发评论；
- OAuth 后读取收藏/关注并形成个人画像；
- 实时多人房间、私信、关注关系或站内社交图谱；
- 未经官方确认的开放平台接口、额度、跨域、字段和 skill 调用方式。

这些能力需要官方权限、隐私边界和社区治理设计。本轮 Demo 以可运行、可解释、可溯源为先。

## 演示验收顺序

1. 进入一个真实问题快照；
2. 看到不同回答、成立条件和原文来源；
3. 选择观点坐标并提交回应；
4. 展示四维体检和被忽略的对立条件；
5. 点击相反立场作者回到知乎原文；
6. 复制邀请链接，让朋友从同一问题重新复核。
