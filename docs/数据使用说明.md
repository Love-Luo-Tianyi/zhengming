# 数据使用说明

## 数据来源与处理

`tools/raw/` 与 `web/data/topics/` 中的回答标题、短摘录、作者昵称、赞同数、评论数、回答 ID 与原文链接采集自**知乎公开问答页面**，用于本作品的离线演示样本库。默认不调用实时知乎 API。

本作品为独立、非官方演示，与知乎无官方隶属关系；短摘录仅用于观点呈现与溯源，完整内容、最新状态和权利信息以知乎原文为准。

采集是**小规模、定向**的：为 6 个争议话题各选取若干条公开可见的高赞回答，每条都保留完整的作者署名与知乎原文链接，用于观点呈现与溯源，不做用户画像、不做批量抓取、不做二次分发。

## 生产路径

代码保留了**可选的知乎开放平台接口适配层**（`zhihu_search` / `hot_list` / `global_search` / 关注流 / 直答 Agent），但公网 Demo 默认不启用。接口权限、字段、额度、跨域和合规边界均须以知乎官方当期文档为准，待官方复核。拿到并核验 Access Secret 后才可尝试执行：

```bash
ZHIHU_ACCESS_SECRET=xxx node tools/fetch-answers.mjs
node tools/build-dataset.mjs
node tools/validate-dataset.mjs
```

即可用官方接口检索结果重建样本库，替换掉页面采集的样本。`tools/fetch-answers.mjs` 对每个关键词只请求一次并落盘，重复运行不重复消耗额度。

## 隐私边界

- 本作品不收集、不存储任何用户的个人信息、收藏夹内容或社交关系；
- 开放平台 Access Secret 与模型 Key 只写入浏览器 localStorage 或服务端环境变量，不进入代码、URL 或日志；
- 后端只放行必要的知乎接口，并做单 IP 限流。

## 权利归属

作品中的知乎回答摘要与作者信息，版权归原作者所有。若原作者希望自己的内容不出现在本演示样本库中，可通过代码仓库的 Issue 联系，我们会立即移除。
